Licences Xavius NasOS Pro

Base KeePass

Ouvrez votre base KeePass (.kdbx) : le jeton GitHub y est lu automatiquement, et la clé de chaque licence y est rangée (groupe « Xavius NasOS Pro / Licences »). La base est déchiffrée dans ce navigateur uniquement ; ni elle ni votre mot de passe maître ne quittent l'ordinateur.

Connexion

Ce gestionnaire lit et modifie le registre privé Shattxx/nasos-licences avec un jeton GitHub personnel. Le jeton reste dans ce navigateur, il n'est envoyé qu'à GitHub.

Jeton « fine-grained » : dépôt nasos-licences uniquement, permissions Contents : Read and write et Actions : Read and write.

Avec une base KeePass ouverte, le jeton saisi ici y est rangé (entrée « GitHub — gestionnaire des licences ») : plus besoin de le mémoriser dans le navigateur.

Nouvelle licence
